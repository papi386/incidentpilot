# V1.2.3 Acceptance Checklist

## Build / release gate

- [ ] `npm run security:workflows` passes
- [ ] `npm run security:workflows:test` passes adversarial YAML fixtures
- [ ] `npm run typecheck` passes
- [ ] `npm test` passes unit tests
- [ ] `npm run test:integration -w @incidentpilot/control-plane` passes Cloudflare-native integration tests
- [ ] `npm run security:deps` has no unmitigated High/Critical advisory
- [ ] migrations `0001` through `0006` apply to a clean local DB

## Webhook / route security

- [ ] invalid signature creates no delivery state
- [ ] fresh signed failure creates one incident/workflow
- [ ] redelivery maps to the same incident/workflow
- [ ] same delivery ID + different authenticated body is rejected
- [ ] oversized webhook is rejected before incident creation
- [ ] webhook kill switch creates no incident
- [ ] OAuth callback rejects missing/mismatched browser binding before provider exchange
- [ ] expired OAuth flow is rejected
- [ ] already-consumed OAuth state replay is rejected
- [ ] correctly hashed expired session is rejected
- [ ] logout deletes the active server-side session and expires the browser cookie

## OAuth / installation concurrency

- [ ] User-Agent rotation does not change the local rate-limit identity
- [ ] bounded OAuth cleanup uses indexed/limited deletion
- [ ] active-flow capacity check + insert is atomic under concurrent attempts
- [ ] OAuth consume + retrieval is one atomic `UPDATE ... RETURNING`
- [ ] concurrent installation refreshes cannot let an older generation delete newer associations

## Evidence / crypto / D1

- [ ] repository token is one-repo/read-only and not persisted
- [ ] unsafe log redirect is blocked without forwarding bearer credentials
- [ ] provider JSON/log byte and total deadlines are enforced
- [ ] actionable job filtering happens before the 4-job limit
- [ ] oversized individual log lines do not hide later diagnostics
- [ ] max graph is capped at 48 items / 96 edges
- [ ] max graph persistence estimate is <=24 statements and hard budget <=24
- [ ] secrets in sample evidence are redacted
- [ ] external content remains `NEVER_INSTRUCTIONS`
- [ ] D1 contains opaque HMAC evidence indexes rather than raw paths/dedupe keys
- [ ] D1 contains ciphertext rather than plaintext content/repository metadata
- [ ] item AAD v2 can be reconstructed using persisted envelope fields only
- [ ] edge metadata is encrypted and recoverable
- [ ] save -> discard original objects -> reload D1 -> decrypt reproduces complete graph
- [ ] injected edge-write failure rolls back snapshot replacement
- [ ] maximum graph persists and reloads through the real D1 adapter
- [ ] AES-GCM tamper/AAD mismatch fails

## Fail-safe / retry / resource exhaustion

- [ ] evidence kill switch is re-read inside every collection retry attempt before token/API use
- [ ] local security validation failures do not enter transient retry loops
- [ ] GitHub 429 obeys provider retry guidance
- [ ] request deadline remains active through response-body consumption
- [ ] installation-token broker uses the same full-operation deadline principle
- [ ] D1 read/write/capacity exhaustion is classified `RESOURCE_EXHAUSTED`
- [ ] D1 exhaustion is non-retryable inside the Workflow and avoids retry storms
- [ ] transient collection exhaustion terminates `FAILED_SAFE`
